{{ site.title }} lo gestiona un pequeño equipo de mantenedores. Por ahora, la forma de contactar con ellos es **GitHub Issues**, en el repositorio público del proyecto:

<p><a class="mw-ui-button" href="https://github.com/{{ site.repository }}/issues/new">Contactar con los mantenedores en GitHub →</a></p>

Necesitas una cuenta gratuita de GitHub. También puedes [consultar las incidencias existentes](https://github.com/{{ site.repository }}/issues) para ver si tu pregunta ya se ha planteado.
{% if site.contact_email != "" %}
Si no puedes usar GitHub, escribe a **[{{ site.contact_email }}](mailto:{{ site.contact_email }})**.
{% endif %}
## Antes de escribir

- **Para informar de un error o sugerir un artículo,** lee primero [cómo contribuir](../contribute/) para que tengamos todo lo necesario.
- **Las incidencias son públicas.** No incluyas datos personales que no quieras que vea cualquiera.
- **No podemos ayudar con** la recuperación de fondos perdidos, claves privadas o contraseñas, decisiones de inversión ni problemas con exchanges y monederos. Desconfía de quien diga ser de {{ site.title }} y ofrezca «recuperar» criptomonedas: es una estafa habitual. Los mantenedores nunca te pedirán tu frase semilla ni tus claves privadas.

## Prensa y asuntos legales

Para consultas de prensa, derechos de autor o asuntos legales, abre una incidencia que empiece por «Prensa» o «Legal» en el título. Un mantenedor responderá allí y, si hace falta, acordará un canal privado.
