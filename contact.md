{{ site.title }} is run by a small team of maintainers. For now, the way to reach them is **GitHub Issues** in the project's public repository:

<p><a class="mw-ui-button" href="https://github.com/{{ site.repository }}/issues/new"><b>Contact the maintainers on GitHub →</b></a></p>

You need a free GitHub account. You can also [browse existing issues](https://github.com/{{ site.repository }}/issues) to see whether your question has already been raised.
{% if site.contact_email != "" %}
If you can't use GitHub, you can email the maintainers at **[{{ site.contact_email }}](mailto:{{ site.contact_email }})**.
{% endif %}
## Before you write

- **To report an error or suggest an article**, please read [how to contribute](../contribute/) first so we have everything we need.
- **Issues are public.** Don't include personal details you wouldn't want anyone to see.
- **We can't help with** recovering lost funds, private keys or passwords, investment decisions, or problems with exchanges and wallets. Beware of anyone who contacts you claiming to be from {{ site.title }} and offering to "recover" crypto. That is a common scam. The maintainers will never ask for your seed phrase or private keys.

## Press and legal

For press, copyright or legal enquiries, open an issue with "Press" or "Legal" at the start of the title. A maintainer will reply there and, if needed, arrange a private channel.
