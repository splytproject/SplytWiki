This **crypto glossary** explains language commonly encountered in cryptocurrency articles, applications and online communities. Slang is informal and context-dependent; an enthusiastic slogan does not establish that a project is useful or that an investment will succeed. Technical terms are grouped by subject so readers can compare related ideas.

For a first reading, start with *blockchain*, *wallet*, *private key*, *transaction*, *gas* and *token*. For practical account protection, see [cryptocurrency wallets](../Cryptocurrency_wallet/). The definitions below are quick explanations; linked articles provide mechanisms, examples and limitations.

## Community slang

| Term | Plain-language meaning | Context or caution |
|---|---|---|
| **HODL** | Hold an asset rather than sell during volatility | Originated in a misspelled 2013 forum post; “hold on for dear life” is a later reinterpretation.[^hodl] |
| **WAGMI** | “We're all going to make it” | A statement of group optimism, not a promise of returns |
| **NGMI** | “Not going to make it” | Often a dismissive joke; it is not meaningful analysis |
| **GM** | “Good morning” | A common community greeting |
| **FOMO** | Fear of missing out | Can encourage decisions based on urgency instead of evidence |
| **FUD** | Fear, uncertainty and doubt | Sometimes used to dismiss valid criticism as well as rumours |
| **DYOR** | Do your own research | A slogan that does not excuse misleading promotion |
| **NFA** | Not financial advice | A disclaimer that does not establish the accuracy of a claim |
| **Rekt** | Suffered a severe loss | Informal spelling of “wrecked” |
| **Whale** | A holder large enough to matter in a particular market | No universal token amount defines a whale |
| **Diamond hands** | Someone determined to keep holding | Persistence can preserve either a good position or a bad one |
| **Paper hands** | Someone described as selling quickly | Often social pressure rather than a useful description of risk |
| **Bagholder** | Someone left holding an asset after a large decline | The term says nothing about future recovery |
| **Moon** | A hoped-for dramatic price rise | “To the moon” expresses enthusiasm |
| **Pump** | A rapid rise in price | Can result from ordinary demand or organized manipulation |
| **Dump** | Heavy selling or a rapid price decline | Context is needed to identify the cause |
| **Shill** | Promote an asset enthusiastically, often with an undisclosed interest | Check incentives and supporting evidence |
| **Degen** | A participant embracing unusually speculative activity | A community label, not a measure of expertise |
| **Rug pull** | Project insiders extract value or abandon a promoted venture to holders' detriment | Removing liquidity is one possible form; a falling price alone does not prove fraud.[^rug] |

## Assets and ownership

| Term | Meaning |
|---|---|
| **Cryptocurrency** | A digital asset system using cryptography and a distributed ledger for ownership and transfers |
| **Coin** | Usually the native asset of a blockchain, although everyday usage is inconsistent |
| **Altcoin** | A cryptocurrency other than Bitcoin |
| **Token** | An asset represented on a network, often by a smart contract |
| **Fungible** | Interchangeable with another unit of the same kind |
| **NFT** | A non-fungible token distinguished from other tokens by its identifier; ownership does not automatically grant copyright |
| **Stablecoin** | A token designed to track a reference value, such as one dollar |
| **Peg** | The target exchange value an asset aims to maintain |
| **Depeg** | A meaningful departure from that target value |
| **Governance token** | A token associated with participation in specified decisions |
| **Utility token** | A token with a stated service or access function |
| **Meme coin** | An asset associated primarily with a joke, cultural theme or community identity |
| **Mint** | Create new units under an asset's rules |
| **Burn** | Remove units from circulation through a defined mechanism |
| **Airdrop** | A token distribution to selected addresses; an unsolicited token can also be bait for a scam |
| **Tokenomics** | The design of token supply, distribution and incentives |

See [altcoins and tokens](../Altcoins_and_tokens/), [NFT standards](../NFT_standards/) and [stablecoins](../Stablecoin/) for the distinctions behind these labels.

## Networks and execution

| Term | Meaning |
|---|---|
| **Blockchain** | A shared record organized into linked blocks |
| **Block** | A group of recorded transactions and associated network data |
| **Node** | A computer participating in a network by checking, storing or relaying information |
| **Consensus** | Rules and processes by which participants agree on accepted history |
| **Validator** | A participant performing protocol duties such as proposing or attesting to blocks |
| **Mining** | Performing proof-of-work computations to compete in block production |
| **Staking** | Committing assets under a proof-of-stake system's rules; commercial products use the word more broadly |
| **Slashing** | A protocol penalty that removes some staked assets for specified violations |
| **Transaction** | A submitted instruction that can change network state |
| **Confirmation** | Inclusion of a transaction in accepted history; stronger assurance can require additional steps |
| **Finality** | The point at which reversal is prevented or becomes exceptionally unlikely under a network's assumptions |
| **Fork** | A divergence in rules or chain history |
| **Gas** | A unit measuring execution work on networks such as Ethereum |
| **Gas fee** | The amount paid for processing a transaction, determined by work and the applicable price |
| **Gwei** | One billionth of an ether |
| **Smart contract** | Blockchain code that processes inputs according to programmed rules |
| **DApp** | A decentralized application that uses network-based backend logic |
| **Oracle** | A mechanism supplying external information to blockchain programs |

The [Ethereum glossary](https://ethereum.org/glossary/) provides further technical terminology; explanations of execution are in [smart contracts](../Smart_contract/).

## Scaling and moving between networks

| Term | Meaning |
|---|---|
| **Layer 1 (L1)** | A base blockchain with its own consensus and transaction history |
| **Layer 2 (L2)** | A system scaling a base network under a defined settlement and security relationship |
| **Rollup** | A system executing transactions outside a base chain and submitting data and commitments or proofs to it |
| **Optimistic rollup** | A rollup using a dispute process to challenge invalid execution claims |
| **ZK rollup** | A rollup using validity proofs; the name does not inherently imply private transactions |
| **Sidechain** | A separate blockchain connected to another network but using its own consensus |
| **Bridge** | A mechanism transferring messages or representations of assets between networks |
| **Sequencer** | A component that orders transactions in a system such as a rollup |
| **Data availability** | Whether information needed to verify or reconstruct state can be obtained |
| **Throughput** | The amount of processing completed in a period; measurement methods matter |

See [blockchain scaling](../Blockchain_scaling/) for tradeoffs that these short definitions cannot fully express.

## Wallets and security

| Term | Meaning |
|---|---|
| **Address** | An identifier used to receive assets or interact with an account |
| **Public key** | Cryptographic information used to verify signatures |
| **Private key** | A secret enabling transaction authorization in a basic key-controlled account |
| **Seed phrase** | Recovery words that can derive a wallet's underlying secrets; never share them |
| **Signature** | Cryptographic authorization of a message or transaction |
| **Custody** | Control and safekeeping of assets or their signing authority |
| **Self-custody** | An arrangement in which the user controls authorization rather than relying on a custodian |
| **Hot wallet** | A wallet whose signing secrets are held in an internet-connected environment |
| **Cold storage** | Keeping signing secrets offline |
| **Hardware wallet** | A dedicated device designed to protect keys and sign internally |
| **Multisig** | An authorization scheme requiring several signatures |
| **Approval** | Permission for a specified contract or party to spend tokens under defined conditions |
| **Phishing** | Deception intended to obtain secrets or harmful authorization |
| **Address poisoning** | Planting a lookalike address in records to encourage a mistaken transfer |

A wallet password, device PIN and seed phrase serve different purposes. A password reset cannot ordinarily replace a missing self-custody recovery secret. See [wallet security](../Cryptocurrency_wallet/).

## Markets, DeFi and governance

| Term | Meaning |
|---|---|
| **Bull market** | A broadly rising market period |
| **Bear market** | A broadly declining market period |
| **Volatility** | The degree of price fluctuation |
| **Liquidity** | The ability to trade without greatly changing price |
| **Spread** | The difference between quoted buying and selling prices |
| **Slippage** | The difference between an expected execution price and the price obtained |
| **Market capitalization** | Price multiplied by circulating supply |
| **FDV** | Fully diluted valuation, using an assumed expanded supply |
| **Leverage** | Exposure enlarged through borrowing or derivatives |
| **Liquidation** | Forced closing or collateral sale under borrowing rules |
| **Collateral** | Assets pledged to support an obligation |
| **DeFi** | Financial services implemented through blockchain applications |
| **DEX** | A decentralized exchange using network-based trading rules |
| **Liquidity pool** | Assets deposited into a contract to support trading or another service |
| **Yield** | A return measured over time; its source and risks need examination |
| **APY** | Annual percentage yield including an assumed compounding effect |
| **DAO** | An organization coordinating decisions through shared governance arrangements, often using blockchain tools |
| **Quorum** | A minimum participation requirement for a valid decision |
| **Delegation** | Assigning voting power or another defined responsibility to a representative |
| **Treasury** | Assets held for an organization's activities |
| **Timelock** | A programmed delay before an action becomes executable |

## Compliance vocabulary

| Term | Meaning |
|---|---|
| **KYC** | Know Your Customer: identifying and verifying a customer |
| **AML** | Anti-money laundering: controls addressing the movement of criminal proceeds |
| **CFT** | Countering the financing of terrorism |
| **VASP** | Virtual asset service provider, a category used in international AML standards |
| **Travel Rule** | Requirements for covered providers to transmit specified transfer-related information |
| **Cost basis** | The acquisition value used when calculating taxable gains under applicable rules |
| **Disposal** | Giving up an asset through a transaction such as a sale or exchange; tax meaning depends on jurisdiction |
