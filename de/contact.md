{{ site.title }} wird von einem kleinen Maintainer-Team betreut. Derzeit erreichen Sie es über **GitHub Issues** im öffentlichen Repository des Projekts:

<p><a class="mw-ui-button" href="https://github.com/{{ site.repository }}/issues/new">Maintainer auf GitHub kontaktieren →</a></p>

Dafür brauchen Sie ein kostenloses GitHub-Konto. In den [bestehenden Issues](https://github.com/{{ site.repository }}/issues) sehen Sie, ob Ihre Frage schon gestellt wurde.
{% if site.contact_email != "" %}
Wenn Sie GitHub nicht nutzen können, schreiben Sie an **[{{ site.contact_email }}](mailto:{{ site.contact_email }})**.
{% endif %}
## Bevor Sie schreiben

- **Um einen Fehler zu melden oder einen Artikel vorzuschlagen,** lesen Sie zuerst, [wie man mitwirkt](../contribute/), damit wir alle nötigen Angaben erhalten.
- **Issues sind öffentlich.** Geben Sie keine persönlichen Daten an, die nicht jeder sehen soll.
- **Wir können nicht helfen bei** der Wiederherstellung verlorener Gelder, privater Schlüssel oder Passwörter, bei Anlageentscheidungen oder bei Problemen mit Börsen und Wallets. Vorsicht vor Personen, die behaupten, von {{ site.title }} zu sein, und anbieten, Kryptowerte „zurückzuholen“. Das ist eine verbreitete Betrugsmasche. Die Maintainer fragen niemals nach Ihrer Seed-Phrase oder Ihren privaten Schlüsseln.

## Presse und rechtliche Angelegenheiten

Für Presse-, Urheberrechts- oder Rechtsanfragen eröffnen Sie ein Issue und beginnen den Titel mit „Presse“ oder „Rechtliches“. Ein Maintainer antwortet dort und vereinbart bei Bedarf einen privaten Kanal.
