{{ site.title }} wird von seinen Herausgebern mit Unterstützung der Leserschaft geschrieben. Sie können Seiten nicht direkt bearbeiten, aber Vorschläge sind willkommen und werden von einer Person geprüft.

## Was Sie vorschlagen können

- **Korrekturen.** Eine Tatsache, die falsch, unklar oder veraltet ist.
- **Fehlende Quellen.** Eine verlässliche Quelle, die etwas in einem Artikel belegt (oder widerlegt).
- **Neue Artikel.** Eine Kryptowährung, ein Protokoll, eine Person, ein Unternehmen oder ein Konzept, das eine eigene Seite verdient. Links in <span style="color:var(--link-new)">rot</span> verweisen auf noch nicht existente Artikel.
- **Verbesserungen.** Bessere Erklärungen, Diagramme oder Beispiele.

## Wie man einen Vorschlag schickt

{% if site.contact_email != "" -%}
Senden Sie eine E-Mail an **[{{ site.contact_email }}](mailto:{{ site.contact_email }})** und fügen Sie Folgendes bei:
{%- else -%}
Ein Vorschlagsformular ist in Arbeit. Bis dahin nutzen Sie bitte die Kontaktdaten auf der [Kontaktseite](/de/contact/) und geben Sie an:
{%- endif %}

1. Den Namen des Artikels (oder den Artikel, den Sie sehen möchten).
2. Was sich ändern soll und warum.
3. Mindestens eine vertrauenswürdige Quelle, z. B. ein Whitepaper, offizielle Dokumentation, Gerichtsunterlagen oder ein seriöser Zeitungsbericht.

## Was wir nicht veröffentlichen

Um {{ site.title }} vertrauenswürdig zu halten, akzeptieren wir nicht:

- werblichen Text, Preisprognosen oder "next 100×"-Behauptungen;
- Empfehlungslinks, Token-Verkaufslinks oder Wallet-Adressen, die um Geld bitten;
- Vorschläge, die vom beschriebenen Projekt bezahlt oder in dessen Auftrag geschrieben wurden, sofern dies nicht offen gelegt wird;
- unbestätigte Gerüchte oder persönliche Angriffe.

Danke, dass Sie helfen, {{ site.title }} zu verbessern.
